# Production deployment checklist

- [ ] Push the final code to GitHub.
- [ ] Import the GitHub repository into Netlify.
- [ ] Set build command to `npm run build`.
- [ ] Set publish directory to `dist`.
- [ ] Choose and verify a clean Netlify site name.
- [ ] Confirm the deployed site uses HTTPS.
- [ ] Test in Chrome.
- [ ] Test in Firefox.
- [ ] Test in Safari.
- [ ] Test on a mobile device or mobile viewport.
- [ ] Capture a real normal-result screenshot.
- [ ] Capture a real loading/Stop screenshot.
- [ ] Capture a real error/Retry screenshot.
- [ ] Add approved screenshots to the README.
